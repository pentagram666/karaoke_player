# 🎤 Karaoke Player Web

Aplicação web de karaokê com suporte a reprodução e gerenciamento de músicas, permitindo upload de arquivos `.KAR` e `.MIDI`, criação de playlists e execução diretamente no navegador.

---

## 🚀 Demonstração

🔗 Acesse a aplicação:
https://karaokeplayer--metalnation666.replit.app/#sunset

---

## 🎯 Objetivo

Desenvolver uma aplicação web interativa para reprodução de karaokê, com suporte a catálogo personalizado de músicas e controle de execução em tempo real.

---

## 🧩 Tecnologias Utilizadas

* Node.js
* Python
* HTML
* CSS
* JavaScript

---

## ⚙️ Funcionalidades

* 🎵 Reprodução de músicas no formato `.KAR` e `.MIDI`
* 📂 Upload de arquivos de karaokê para o sistema
* 📋 Criação e gerenciamento de playlist
* 🔁 Execução automática de músicas em sequência
* 🖥️ Interface interativa para controle de reprodução
* 📁 Organização de catálogo de músicas

---

## 🧠 Arquitetura

A aplicação utiliza uma estrutura híbrida:

* **Frontend:** Interface web para interação do usuário e controle da reprodução
* **Backend:** Processamento de arquivos e lógica de execução utilizando Node.js e Python
* **Integração:** Comunicação entre frontend e backend para gerenciamento de músicas e reprodução

---

## 📦 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/pentagram666/karaoke_player.git
```

---

### 2. Acesse a pasta do projeto

```bash
cd karaoke_player
```

---

### 3. Instale as dependências

```bash
npm install
```

---

### 4. Execute o servidor

```bash
node server.js
```

---

### 5. Acesse no navegador

```bash
http://localhost:3000
```
